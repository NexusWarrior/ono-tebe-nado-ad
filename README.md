# Оно тебе надо

Учебный проект Яндекс Практикума — страница аукциона вещей, в которые никто не верил. Работа выполняется по макету Figma с использованием HTML и CSS.

**Текущий этап:** подготовлена HTML-разметка с содержимым из макета, подключены шрифты и базовые стили. Детальная вёрстка ещё впереди: файл `styles/style.css` пока пустой, поэтому страница пока не повторяет внешний вид макета.

## Задача проекта

Сверстать страницу для экрана ноутбука: шапку с навигацией и контактами, обложку, три карточки лотов, раздел об аукционе и подвал. Целевая ширина страницы — 1100 px. Мобильная версия на этом этапе задания не предусмотрена.

Проект помогает освоить семантическую разметку, подключение локальных ресурсов, организацию CSS, Grid, Flexbox и позиционирование элементов.

## Этапы разработки

### 1. Анализ задания

Определены основные секции страницы и повторяющиеся элементы: контакты в шапке и подвале, карточки лотов и затемнение фоновых изображений. Работа организована от общей структуры к детальной стилизации.

### 2. Подготовка структуры

Создан HTML-каркас с элементами `header`, `main` и `footer`. Основное содержимое разделено на секции `cover`, `lots` и `about`. Добавлены меню, заголовки, список карточек и блоки контактов.

### 3. Добавление ресурсов

Из официальной заготовки добавлены папки `fonts`, `images` и `styles`, а также конфигурация проверок Практикума `.github/workflows/tests.yml`.

### 4. Наполнение страницы

В разметку перенесены тексты из макета, добавлены логотипы, социальные иконки и контакты. CSS-файлы подключены в порядке: шрифты → глобальные стили → собственные стили. Для телефона и почты используются ссылки `tel:` и `mailto:`, для навигации по странице — ссылки на идентификаторы разделов.

### 5. Дальнейшее оформление

Следующий этап — расположение элементов с помощью Grid и Flexbox, настройка фоновых изображений, затемнения, типографики и отступов. После стилизации предусмотрена сверка с макетом и чек-листом задания.

## Технологии и решения

| Технология или подход | Применение |
| --- | --- |
| HTML5 | Семантическая структура страницы и иерархия заголовков |
| CSS | Базовые стили и дальнейшее оформление по макету |
| БЭМ-именование | Классы блоков, элементов и модификаторов: `card`, `card__title`, `card_type_film` |
| Локальные шрифты | Raleway Regular и Bold в форматах WOFF и WOFF2 |
| SVG и JPG | Логотипы, социальные иконки и фотографии |
| Git | Учёт файлов и история изменений |

Разметка карточки построена по схеме `ul > li > a > article`: карточки образуют список, а ссылка охватывает каждую карточку целиком. Контакты в шапке и подвале используют общий класс `address` для будущего переиспользования стилей.

Для изображений указаны альтернативные тексты, а для двух меню — доступные названия через `aria-label`. Фоновые фотографии обложки и карточек будут подключены через CSS. Для затемнения подготовлены элементы с общим классом `overlay`.

## Структура проекта

```text
.
├── .github/
│   └── workflows/
│       └── tests.yml
├── fonts/
│   ├── fonts.css
│   ├── Raleway-Regular.woff
│   ├── Raleway-Regular.woff2
│   ├── Raleway-Bold.woff
│   └── Raleway-Bold.woff2
├── images/
│   ├── cover.jpg
│   ├── card-lot-01.jpg
│   ├── card-lot-02.jpg
│   ├── card-lot-03.jpg
│   ├── logo-black.svg
│   ├── logo-white.svg
│   ├── yt.svg
│   ├── vk.svg
│   └── pinterest.svg
├── styles/
│   ├── global.css
│   └── style.css
├── index.html
├── index.js
├── package.json
└── README.md
```

`index.html` содержит разметку и контент. В `global.css` находятся базовые настройки заготовки, включая ширину страницы и сброс отступов. `style.css` предназначен для дальнейшего оформления.

`index.js` и `package.json` остались от первоначального проекта. Скрипт `index.js` не подключён к странице; для текущей вёрстки JavaScript не используется.
